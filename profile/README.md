# Dwahfy

Dwahfy is a modern, self-hosted social media platform inspired by Instagram and Lemon8 — built for privacy, customization, and fun.

This organization hosts the open-source backend and community tools. The official polished app (with the premium UI) is closed-source and available separately.

---

## Repositories

### 🔧 [Dwahfy-Core](https://github.com/Dwahfy/Dwahfy-Core) — Open Source Backend
The core API server built with Node.js, Express, and PostgreSQL. Fully open-source under Apache 2.0 and easy to self-host.

**Features:**
- User authentication & profiles
- Image/video posts with S3-compatible storage (AWS S3, MinIO, Backblaze, etc.)
- Feeds, likes, comments, and follows
- One-command self-hosting via Docker Compose
- Flexible deployment: AWS, VPS, home server, Raspberry Pi

### 🎨 [Community Web UI](https://github.com/Dwahfy/Communuity-Web-UI) — Open for Contributions
A simple, open-source web client built for self-hosters and contributors. Includes a basic feed, posts, likes, and follows. Whether you want to improve the UX, polish the design, or add features — contributions are welcome.

> **Note:** The official Dwahfy app UI is separate and proprietary. This community UI is its own open project — what you build here is yours to be proud of.
